# Ñapi Barber

- Página estática de un solo archivo (`index.html`), sin build. Se publica en Vercel tal cual.
- Al terminar cada cambio: commit y push a la rama de trabajo **y también a `main`** (`git push origin HEAD:main`), para que el dueño lo revise.
- Datos del negocio (precios, horarios, direcciones, Instagram, fotos) solo en el bloque `CONFIG` de `index.html`. No inventar datos: lo que falte queda como placeholder.
